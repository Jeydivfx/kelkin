# اصلاح کادر وضعیت پلیر

کادر خطای پلیر در activity_player.xml قرار دارد و دیالوگ AlertDialog نیست؛ اصلاح قبلی دیالوگ‌ها این بخش را پوشش نداده بود.

عرض کادر محدود و پس‌زمینه با دیالوگ‌های اپ هماهنگ شد. دکمه‌ها از bg_dialog_button با متن سیاه استفاده می‌کنند؛ tintهای Android و Material هر دو حذف شدند تا رنگ پیش‌فرض بنفش اعمال نشود. هنگام نمایش پیام بارگذاری یا خطا، کنترل‌های پلیر پنهان و نمایش خودکارشان متوقف می‌شود.

مسدودسازی عمومی HTTP که در اصلاحات قبلی اضافه شده بود برداشته شد؛ آرشیو می‌تواند لینک HTTP و ریدایرکت به CDNهای مختلف داشته باشد. این یعنی انتقال لینک‌های HTTP بدون رمزنگاری مجاز است؛ لینک‌های HTTPS همچنان از اتصال رمزنگاری‌شده استفاده می‌کنند. گواهی‌های معتبر سیستم همچنان بررسی می‌شوند.

اعتبار XML چیدمان و تنظیمات شبکه بررسی شد. تست پخش واقعی این لینک انجام نشده است.
